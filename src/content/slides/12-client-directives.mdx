## Selective Hydration (`client:*` directives)

- **No directive** — Server-rendered HTML only (**0 KB JS**)
- **`client:load`** — Hydrate immediately on page load
- **`client:idle`** — Hydrate once the browser main thread is free
- **`client:visible`** — Hydrate only when scrolled into view
