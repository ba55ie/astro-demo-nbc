## How the Web Actually Renders

- **70–80% of the web** is rendered server-side (~60% PHP)
- Yet we defaulted to building **everything as a React SPA**
- Shipping a full JS runtime just to render static content

> "HTML is the default output rather than a side effect, and JavaScript is optional rather than assumed." — _Adam Lowe_

<aside class="notes">
  - StatCounter data & recent PHP stats reminded us that ~60% of the web runs on PHP, and 70-80% is server-rendered.
  - In SPAs, we pay a heavy tax: client-side waterfalls (`useEffect` -> `fetch` -> spinner) and full-page hydration on mobile devices.
</aside>
