## Why Astro? USPs & Core Principles

- **Server-first API design** — Move expensive hydration off your users' devices
- **Zero JS, by default** — No client JavaScript runtime overhead to slow you down
- **Content-focused & Fast by default** — Nearly impossible to build a slow site
- **UI-agnostic** — Supports **React**, **Preact**, **Svelte**, **Vue**, **Solid**, and Web Components
- **Customizable (100+ Integrations)** — **Tailwind**, **MDX**, React, Vue, Sitemap, and more
- **Easy to use** — You don't need to be an expert to build with Astro

<aside class="notes">
  - Reference: https://docs.astro.build/en/concepts/why-astro/
  - Astro combines the developer experience of modern component frameworks with the raw performance of server-rendered HTML.
  - Notice that Lit was deprecated/removed in recent Astro versions, while React, Preact, Svelte, Vue, Solid, and native Web Components remain first-class.
</aside>
