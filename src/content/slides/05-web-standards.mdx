## Web Standards & HTML First

- **Standard HTML & CSS** — Real `class` and `for` attributes
- **Native Composition** — `<slot></slot>` instead of custom APIs
- **Web Platform APIs** — Standard `fetch()`, `Request`, `Response` & `URL`
- **Long-Term Maintainability** — Web standards don't go obsolete

<aside class="notes">
  - If the Web Platform already has a standard, Astro uses it instead of inventing framework-specific abstractions.
  - Show in IDE: `<slot />` in `src/layouts/DefaultLayout.astro` and native View Transitions.
</aside>
