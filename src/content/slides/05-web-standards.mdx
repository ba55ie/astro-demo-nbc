## Web Standards & HTML First

If the Web Platform already has a standard, Astro uses it instead of inventing a custom API:

- **`<slot></slot>`** — Standard Web Component slot composition instead of React `children`
- **Web `fetch()`, `Request`, `Response` & `URL`** — Standard Web APIs everywhere (`Astro.request`, `Astro.url`)
- **Valid HTML & CSS** — Use standard `class` and `for` (no `className` or `htmlFor` needed!)
- **Native View Transitions & `<script>`** — `@view-transition { navigation: auto; }` and standard DOM scripts

<aside class="notes">
  - Everything you learn in Astro is transferable because it's built on MDN web standards: `<slot />`, `fetch()`, `Request`, `Response`, and `URL`.
  - Long-term maintainability: web standards don't break every major framework version.
</aside>
