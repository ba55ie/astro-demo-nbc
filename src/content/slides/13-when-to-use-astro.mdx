## When to use Astro?

- **Choose Astro** — for content-rich sites, e-commerce, docs & hybrid SSR apps
- **Choose an SPA** — for highly stateful, desktop-like web apps
  - **Admin pages** — can still be build using Astro.
  - **Progressive enhancement** — Don't forget you can _fake it_ with Progressive enhancement like View Transitions.
- **Keep React for interactive UI** — let Astro handle the rest with fast HTML
