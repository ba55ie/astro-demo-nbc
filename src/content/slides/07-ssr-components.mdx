## Simplicity: `.astro` Components

- **Code Fence (`---`)** — Runs only on the server, never in the browser
- **HTML Template** — JSX-like expressions with standard HTML
- **Type-Safe `Astro.props`** — Built-in TypeScript
- **Composition** — with `<slot>`
- **Zero Client Footprint** — Pure HTML + CSS output

    - `src/components/Navigation.astro`
