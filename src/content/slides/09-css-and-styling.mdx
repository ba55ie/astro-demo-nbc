## CSS in Astro

- **Import CSS Anywhere** — In layouts, pages, or components
- **Component `<style>` Tags** — Automatically scoped out of the box
- **Zero Runtime Overhead** — No CSS-in-JS bundle cost
- **Global Escape Hatches** — `:global()` and `<style is:global>`
